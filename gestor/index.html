Parámetros de Conexión

Cómo Conectar tu n8n en Producción

1. Inicia sesión en tu instancia de n8n (o ejecútala en Docker con n8n start).

2. Ve a Settings → n8n API y genera una nueva API Key.

3. Pega la clave aquí. Todas las acciones de subida de facturas, recepción en Correos_cor y cambios en BasCont dispararán automáticamente tus flujos.

⚡ Integración desacoplada: El proyecto sigue funcionando con normalidad incluso si la instancia externa de n8n está apagada o reiniciando.
