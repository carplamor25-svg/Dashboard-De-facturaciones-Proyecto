Recepción y Entrega por Correo (EmailJS / SMTP)

Pipeline desatendido de facturas adjuntas

El cliente envía sus facturas por correo electrónico. El worker las descarga, verifica la firma digital, corre la IA local de extracción y le envía de vuelta un correo con el PDF consolidado y la URL privada firmada.

Integrado con n8n y scripts automáticos

Ciberseguridad y Borrado Demostrable

OWASP ASVS Nivel 2 · ENS · RGPD Art. 5.1.c

Las contraseñas se almacenan con hash Argon2id. La base de datos aplica políticas de aislamiento RLS (Row-Level Security) para que ninguna empresa pueda leer datos de otra. Los archivos temporales se destruyen con sobreescritura segura emitiendo un certificado con hash SHA-256.
