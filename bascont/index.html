Ciberseguridad OWASP Top 10 & Respaldo de Base de Datos

Mitigaciones implementadas para garantizar que nadie pueda acceder o alterar datos sin permisos.

Controles OWASP Top 10 Activos en BasCont

A01: Broken Access Control

Mitigado mediante PostgreSQL Row-Level Security (RLS). Los usuarios solo pueden ver y modificar registros vinculados a su tenant_id.

A02: Cryptographic Failures

Contraseñas almacenadas con función hash Argon2id (salt aleatorio de 16 bytes). Conexiones cifradas exclusivamente con TLS 1.3.

A03: Injection (SQLi / XSS)

Consultas parametrizadas al 100% (prepared statements). Prohibida concatenación de cadenas en sentencias SQL.

A09: Security Logging & Monitoring

Registro inmutable de cada creación de usuario, alteración de columnas o consulta administrativa con IP y timestamp.
